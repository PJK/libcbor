# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report them privately through [GitHub private vulnerability reporting](https://github.com/PJK/libcbor/security/advisories/new) (the "Report a vulnerability" button on the [Security tab](https://github.com/PJK/libcbor/security)). Include a description of the issue, the affected versions, and an input or steps that reproduce it.

libcbor is maintained in spare time on a best-effort basis. I will acknowledge the report, coordinate a fix and a release, and publish a [security advisory](https://github.com/PJK/libcbor/security/advisories) crediting the reporter.

## Supported versions

Security fixes are released for the latest minor version only.
